# Pumpkin Pie

**Pumpkin Pie** is a small, story-driven RPG developed by **Miguel Torres** under **Studio Infinite Loom**.  
Originally created for a game jam, the project has evolved into a personal initiative to learn the **full process of developing and publishing a complete game**.

---

## 🎮 Project Overview

Pumpkin Pie is a cozy, narrative-driven RPG that emphasizes story, character interaction, and atmosphere.  
The game focuses on combining simple but engaging gameplay mechanics with meaningful storytelling — serving as both a technical and creative milestone in independent game development.

## 🚀 Features

- Dialogue and quest systems for story progression  
- Dynamic character interactions and world exploration  
- 2D/3D mixed art style blending hand-painted visuals with simple 3D scenes  
- Focused on emotional storytelling through minimalist mechanics  

---

## 🎯 Goals

Pumpkin Pie began as a **game jam project** and is now being expanded into a fully realized small-scale release.  
The project’s primary objective is to complete and **publish a finished game** by the end of the **Fall 2025 college semester**.

---

## 🏗️ Status

**Status:** 🧩 *In Development*  
**Phase:** Extended development for final release  
**Goal:** Fully playable, polished build ready for public release by semester’s end

## 🧠 Development Focus
